# Velun ZAP

Landing page de um assistente de atendimento com IA para WhatsApp, voltado a pequenos e médios negócios.

> 🚧 **Projeto em andamento** — estrutura e visual já funcionais, alguns espaços (fotos e depoimentos) ainda são placeholders aguardando conteúdo real.

🔗 **No ar:** [veluntech.netlify.app]

## Sobre

O Velun ZAP atende os clientes de um negócio direto no WhatsApp: tira dúvidas, qualifica quem tem interesse real e só chama o dono quando a decisão é dele. Esta página serve como vitrine do serviço, com CTA direto pro WhatsApp.

## Tecnologias

- HTML5
- CSS3 (vanilla, sem framework)
- JavaScript vanilla

Sem dependências externas além das fontes do Google Fonts (Space Grotesk, Inter, JetBrains Mono).

## Estrutura

```
├── index.html      → estrutura da página
├── styles.css       → visual (tema escuro, cores da marca, animações)
└── script.js         → chat animado, scroll reveal, FAQ e menu
```

Os três arquivos precisam ficar na mesma pasta para funcionar (caminhos relativos).

## Funcionalidades já implementadas

- Chat de WhatsApp simulado e animado no hero
- Tema escuro único, com paleta de cores própria (verde, azul, dourado, roxo, coral)
- Menu fixo com sombra dinâmica ao rolar e sublinhado animado nos links
- Revelação suave dos elementos ao rolar a página (scroll reveal)
- Seções: demonstração, como funciona, recursos, sobre, planos, FAQ
- Botão flutuante de WhatsApp com pulso
- Divulgação cruzada com a Velun Tech
- Totalmente responsivo (mobile-first)
